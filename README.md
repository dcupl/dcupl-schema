# dcupl-schema
Generated JSON schemas for the dcupl editor files: models, loader configuration, REST API templates, workflows and test configuration.

The files in `bin/` are generated by [dcupl/dcupl-onto](https://github.com/dcupl/dcupl-onto) from a published `@dcupl/*` SDK version and published by its *Publish schemas* workflow. Never edit them by hand; `bin/schemas.manifest.json` records the SDK version (`sdkVersion`) and the source of every schema.

- `main` carries the schemas of the newest SDK beta (`https://raw.githubusercontent.com/dcupl/dcupl-schema/main/bin/<file>`)
- every publish is tagged `v<sdk version>` so consumers can pin, e.g. `https://raw.githubusercontent.com/dcupl/dcupl-schema/v2.0.0-beta.25/bin/dcupl.api.vscode.schema.json`

Please see the dcupl documentation for further information - https://docs.dcupl.com

- Loader configuration - https://docs.dcupl.com/docs/basics/loader/overview/
- Model configuration - https://docs.dcupl.com/docs/basics/model/overview/
- Schema - https://docs.dcupl.com/docs/basics/tools/json-schema/
